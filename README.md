# Arno Slice

My portfolio as a slicing game. Projects, pages (About, Work, Contact, CV) and skills fly up the screen; slice a project or page to unlock it and read about it. Bugs cost a life, or play in Zen mode without them. Everything you find stays in the bar at the bottom, and "See everything" shows the whole portfolio as a plain list.

Built with TypeScript, HTML canvas and CSS, using Vite. No framework.

## Run it

```bash
npm install
npm run dev     # local dev server
npm run build   # production build in dist/
```

## Content

All personal content lives in `src/data.ts`, mirrored from my main portfolio ([Chrome-portfolio](https://github.com/Arno-Boenders/Chrome-portfolio)). Screenshots and the CV are in `public/`.
